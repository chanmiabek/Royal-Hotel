# 🏢 PROJECT:

# 🏨 Royal Hotel Management System

A scalable, full-featured Hotel Management System built with # Django & Django REST Framework, designed to streamline hotel operations, enable multi-vendor management, and support subscription-based services.

## 🚀 Features
- Room booking
- Multi-vendor system
- Subscription plans

## 🛠️ Tech Stack
- Django
- PostgreSQL

## 🌐 Live Demo
https://royal-hotel-mwb5.onrender.com

## 🔐 Authentication

JWT-based authentication using djangorestframework-simplejwt
Role-based access:
-Customer
-Vendor
-Admin
